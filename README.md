# Respawn Gaming Lounge

A responsive landing page concept for **Respawn Gaming Lounge**, a fictional gaming venue in Konstanz, Germany. The page highlights the lounge's gaming setup, session packages, and community.

## Features

- Responsive layout for desktop and mobile screens
- Mobile navigation menu
- Gaming setup, pricing, and community sections
- Email links for session inquiries and community contact
- Automatically updated copyright year
- Google Fonts and remote Unsplash photography

## Project files

| File | Description |
| --- | --- |
| `index.html` | Page structure and content |
| `style.css` | Layout, responsive styling, and visual design |
| `script.js` | Mobile menu behavior and current copyright year |

## Run locally

No build tools or dependencies are required.

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.

The page loads its fonts and photos from external services, so an internet connection is needed to display those assets. The rest of the page is served from the local files.

## Demo and contact links

The booking and community links open pre-filled email messages. They do not submit bookings or connect to a backend. Update the email addresses and links in `index.html` before using this project for a real venue.

## Content notice

This is a fictional portfolio concept. The venue address, hours, prices, age notice, email address, and phone number are sample content; replace or verify them before publishing for real-world use.
